<original_problem_statement>
The user wants to build a mobile app for tattoo artists named BODY BOUND stencil generator. The core function is to convert a realistic photo into a simplified line drawing/stencil for iOS and iPad.

**PRODUCT REQUIREMENTS**:
1.  **Photo to Stencil Conversion**: The app's primary feature is to convert photos into three stencil versions (Light, Medium, Heavy). The AI must trace the source image with high precision, preserving the original image's orientation.
    *   **Light**: Simple, clean outlines.
    *   **Medium**: Simple lines mixed with dotted reference lines for contour, shape, and shading.
    *   **Heavy**: Simple lines with contour lines and extra detail.
2.  **AI Reliability**: The system must have a fallback from Google Gemini to OpenAI if the primary provider fails.
3.  **UI/UX**: The app should have a dark luxury theme, a welcome page, an Instagram-style photo picker, and a maximized image preview area. An in-app onboarding tutorial should guide first-time users.
4.  **Save/Export**: A unified Save button should provide options to:
    *   Save to the app's internal gallery (not yet implemented).
    *   Save the final stencil to the device's photo gallery.
    *   Export a layered PSD file to Procreate, with the original photo and the stencil on separate layers.
5.  **Stencil Editing (Procreate-style)**: After generating a stencil, the user should be able to enter a full-screen Edit Mode with the following capabilities:
    *   The feature should be disabled on iPhones.
    *   Drawing must be possible **only with an Apple Pencil on iPad**. Finger touches should not draw but instead be used for navigation.
    *   Pinch-to-zoom and two-finger pan functionality with high sensitivity.
    *   Drawing on a zoomed/panned canvas must be accurate (no offset).
    *   A vertical slider on the left for brush size.
    *   Double-tap to undo.
    *   Pencil sensitivity must be high enough to create small dots and dashes with quick taps.
    *   A newly generated stencil should not overlay an image currently being edited.
6.  **Individual Stencil Regeneration**: Allow the user to regenerate a single stencil style (e.g., Medium) without regenerating all three.
</original_problem_statement>
