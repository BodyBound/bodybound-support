**original_problem_statement**: The user wants to build a mobile app for tattoo artists. The app should take a realistic photo and convert it into a simplified line drawing, blueprint, or stencil. Key features include the ability for the user to adjust clarity and line weight, reduce image noise for cleaner lines, and use edge detection technology. The goal is to produce a clean stencil without unnecessary details.

**PRODUCT REQUIREMENTS**:
1.  **Photo to Stencil Conversion**: Core functionality to turn a photo into a tattoo stencil.
2.  **Image Source**: Allow users to upload from their gallery or take a new photo with the camera.
3.  **Adjustable Parameters**: Provide controls (like sliders) for users to adjust the stencil's appearance (e.g., clarity, line weight, noise reduction). This was later deprecated for the AI mode.
4.  **Image Cropping**: Allow users to crop the image before processing.
5.  **Background Removal**: Allow users to remove the background from the image.
6.  **AI-Powered Generation**: The user wants an AI-powered stencil generation that intelligently creates clean line art, similar to a reference app (StencilAI).
7.  **Full-Size Preview**: Allow users to view the generated stencil in a full-screen, zoomable view.
8.  **Compare to Original**: Provide an easy way for users to compare the generated stencil with the original photo.
9.  **Export Options**: Allow users to save the final stencil to their device's gallery, print it, or share it.

**User's preferred language**: English
