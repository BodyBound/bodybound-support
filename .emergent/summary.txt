<original_problem_statement>
The user wants to build a mobile app for tattoo artists named BODY BOUND stencil generator. The core function is to convert a realistic photo into a simplified line drawing/stencil.

**PRODUCT REQUIREMENTS**:
1.  **Photo to Stencil Conversion**: The app's primary feature is to convert user-provided photos into tattoo stencils. The user has requested a Handmade Stencil option that generates three distinct versions for comparison:
    *   **Light**: Clean lines with no shading or solid black fill.
    *   **Medium**: Clean lines with texture/contour lines (cross-hatching, stippling) but no solid black fill.
    *   **Heavy**: Lines with both texture/contour and a moderate amount of solid black fill.
2.  **AI Prompting**: The AI generation must strictly trace the source image, maintaining the exact composition, poses, and proportions. It should not be a creative reinterpretation.
3.  **UI/UX**:
    *   A welcome/cover page should appear on every app launch with the text Transform photos into tattoo stencils as good as handmade and a Get Started button.
    *   The overall app aesthetic should be a dark luxury theme, with a black leather feel and brass/gold filigree accents.
    *   The Generate button should always be available to allow users to switch between stencil styles and regenerate.
4.  **Export/Save**: A critical requirement is for the user to be able to save the final stencil to their device's photo gallery.
5.  **Gallery**: An in-app gallery to browse previously saved stencils, with an option to delete them.
</original_problem_statement>
