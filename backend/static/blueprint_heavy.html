Blueprint Heavy+ — Production Standard

This is now the default behaviour of /api/ai-stencil and /api/process_stencil_job. Every stencil the app generates follows this standard.

Locked-in rules:
  • Line-only. No fills, no gray, no shading. 100% line-based.
  • Four-tier hierarchy: Primary (bold outer contours, foreground) / Secondary (medium internal structure, facial features) / Tertiary (fine texture, hair flow) / Dotted (light facial guides & form transitions). Lines must NOT be uniform weight. Foreground reads stronger than background.
  • Heavy+ detail policy: preserve detail, reduce visual noise ~10–20%. Hair follows directional flow (not random strands). Texture is selective, not full-surface coverage. Facial dotted guides retained. Avoid clutter.
  • Consistency: temperature=0.0 is now the default. Same reference → consistent structure → predictable line placement.
  • Post-processing: Otsu thresholding removed. Grayscale line values preserved → anti-aliased edges, line-weight variation, and dotted-line integrity now match the raw AI output. Background still removed via alpha channel (transparent PNG).
  • Refinement pass: controlled clarity lift — subtle strand break-up (~10–15%), directional micro-lines + highlight-flow guides in hair, slightly clearer plane-change transitions on the face. No density increase, no fuzz. New marks REPLACE weak lines; they do not stack.
  • Depth refinement (targeted, ~10–15% lift in background/accessories ONLY): improved layer separation in background hair/dreads/cloak/fur, subtle material indication on fabric, slightly more bone/crack/overlap detail on headdresses. Priority: FOREGROUND > FACE > STRUCTURE > BACKGROUND — face untouched.
  • Detail priority: STRUCTURE > FLOW > TEXTURE. Readability always wins.
  • Removed entirely: fill logic, shading generation, structure-altering "enhancement", random black region creation.
