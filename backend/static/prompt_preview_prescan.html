AI Pre-Scan — v2 (Structure-Guidance Only)

Same base prompt, same style ("Heavy"). Only difference: whether the structural-guidance preamble was prepended.

What was wrong in v1 (regression fix):
v1 preamble contained drawing-technique instructions ("ultra-fine line weight", "simpler in shadow regions", enhancement hints). The model interpreted those as softening directives and weakened the line hierarchy. Base prompt output was sharper than pre-scan output.

v2 change: the preamble is structural-guidance only. It names what must be captured from the reference, never how to draw it. Line weight, density, and hierarchy remain owned exclusively by the base prompt. Line-hierarchy preservation ("strong contours stay strong, fine detail never collapses") is now an explicit Layer 1 constraint. Enhancement-hints block removed entirely.
Layer 1 — Universal Constraints (hard, always applied): preserve subject count, pose, orientation, framing, gaze, identity, line hierarchy, and edge sharpness. No softening, blurring, denoising, or normalization. Never overrides the base prompt.
Layer 2 — Subject-Type Detection: classifies into exactly one of portrait / animal / object / landscape / stylized_artwork.
Layer 3 — Structural Checklist: features to CAPTURE from the reference for the detected category. No drawing-technique language.
