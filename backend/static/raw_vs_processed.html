Raw AI Output vs Post-Processed — Side by Side

This page proves post-processing is non-destructive. Each row shows the original reference, the raw base64 PNG returned by Gemini (no processing applied), and the final post-processed image the app delivers.

What post-processing actually does (current):
  1. Decode PNG.
  2. Convert to grayscale (removes color cast, preserves full 0–255 range).
  3. Diagnostic: count near-black pixels (<40/255). Log FILL VIOLATION SUSPECTED if >5% — read-only, no pixel changes.
  4. Compose transparent PNG: RGB = black everywhere, alpha = 255 − grayscale. Pure white → transparent, mid-gray → partial alpha, pure black → fully opaque.
  5. Save PNG, return.
Removed: Otsu thresholding, binary conversion, Gaussian pre-blur, forced inversion. None of that runs.
